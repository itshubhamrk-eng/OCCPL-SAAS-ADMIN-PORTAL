# ADR-0005: Versioned REST APIs with RFC 9457 problem details

- Status: Proposed · Date: 2026-10-13

## Decision
Path versioning `/api/v1`, DTOs only, RFC 9457 error bodies with a stable `code` field and
`correlationId`, offset pagination (max 100) and keyset pagination for very large lists,
`ETag`/`If-Match` optimistic concurrency, `Idempotency-Key` on creates and external callbacks.
OpenAPI generated by springdoc; Angular clients generated from it.

## Consequences
+ Consistent contracts for the portal and product services; typed clients.
− Breaking changes require `/v2`; additive changes only within a version.
